# Excel Learning Simulator - Theme System

## Available Style Templates

The Excel Learning Simulator includes a comprehensive theme system with **10 pre-built style templates** that completely transform the app's visual appearance. You can easily switch between themes using the "Theme" button in the toolbar.

## 🎨 How to Use Themes

### Switching Themes:
1. Click the **"Theme"** button with palette icon in the toolbar
2. Browse the visual theme gallery
3. Click any theme card to apply it instantly
4. Your selection is automatically saved

### Theme Persistence:
- Your theme choice is saved to browser localStorage
- Theme persists across sessions and page refreshes
- Each device/browser stores its own theme preference

### Visual Preview:
- Each theme card shows a live preview with:
  - Gradient header preview
  - Button style preview
  - Color accent indicators (success, warning, info)
- Active theme displays a green checkmark

## 🔧 Technical Details

### What Gets Themed:
- **Sidebar background** - Left scenario panel
- **Popup panels** - Floating information panels
- **Buttons and controls** - All interactive elements
- **Modal headers** - Welcome modal, help guide, theme selector
- **Progress indicators** - Task completion badges
- **AI Tutor accents** - Chat interface highlights
- **Links and highlights** - All clickable elements

### CSS Variables Applied:
Each theme sets comprehensive CSS variables:
- `--theme-primary`, `--theme-primaryDark`, `--theme-primaryLight`
- `--theme-secondary`, `--theme-accent`
- `--theme-background`, `--theme-surface`
- `--theme-text`, `--theme-textLight`
- `--theme-border`
- `--theme-success`, `--theme-warning`, `--theme-error`, `--theme-info`
- `--theme-gradient-primary`, `--theme-gradient-header`, `--theme-gradient-button`
