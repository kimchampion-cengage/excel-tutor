# AI Tutor for Excel

AI Tutor for Excel is a browser-based learning prototype that lets students practice a retail data preparation and analysis workflow in a simulated spreadsheet. Learners work through a checklist, receive contextual hints, and can ask the in-app tutor questions about Excel concepts.

> **Live app:** [kimchampion-cengage.github.io/excel-tutor](https://kimchampion-cengage.github.io/excel-tutor/)
> **Source repository:** [github.com/kimchampion-cengage/excel-tutor](https://github.com/kimchampion-cengage/excel-tutor)

The app was exported from Figma Make and is being developed as a React application. The original Figma design is [AI Tutor for Excel](https://www.figma.com/design/heoo0rKDM4sTSbBIqYv5bJ/AI-Tutor-for-Excel).

## What learners can do

- Open a retail inventory analysis scenario and review its objectives.
- Import sample retail data into an editable spreadsheet simulation.
- Edit cells and enter a limited set of formulas through the formula bar.
- Add, rename, select, and delete worksheets.
- Follow an 11-step checklist grouped by task.
- See a hint for the first unfinished step; after all steps are complete, the panel changes to **Session Complete**.
- Ask the in-app tutor questions or choose a suggested question.
- Write a 100–150 word methodology reflection after completing the checklist.
- Print the workbook using the browser print dialog.

The interface uses React Magma 7 for selected components and the design-system foundation. The spreadsheet itself is a teaching simulation, not a full replacement for Microsoft Excel.

## Learning workflow

The scenario guides learners through these steps:

1. Import the retail inventory data.
2. Organize the data for analysis.
3. Examine the dataset for missing values, inconsistent entries, and formatting problems.
4. Clean the data and address data-quality issues.
5. Create derived variables and date components.
6. Set up a descriptive statistics table.
7. Calculate mean, median, standard deviation, minimum, maximum, range, count, and sum.
8. Include Price, Sold, Unit Cost, Total Sales, Total Cost, and Total Profit in the summary.
9. Place the results on a separate worksheet named `Descriptives`.
10. Prepare the workbook for printing.
11. Make the workbook clear for another analyst.

Some checklist items are marked automatically when the app detects related activity. Other items can be checked manually. The automatic checks are prototype heuristics: for example, editing a non-empty cell can satisfy the cleaning step, and entering formulas in the expected columns can satisfy the derived-variable step. They do not validate every result as Excel would.

After all 11 checklist steps are complete, the reflection section unlocks. Submitting the reflection requires 100–150 words.

## Technology

- React 18.3
- React Router 7 with hash-based routing for GitHub Pages
- Vite 6
- React Magma 7
- TypeScript and JSX
- Tailwind CSS 4 and project-specific CSS
- Node.js 20 for the GitHub Pages build

There is no server or account system. The app is a static client-side site.

## Run locally

### Requirements

- Node.js 20
- npm

### Install and start

```bash
npm ci
npm run dev
```

Vite prints the local URL in the terminal. The default is usually [http://localhost:5173](http://localhost:5173).

To create a standard production build for local hosting:

```bash
npm run build
```

The generated files are written to `dist/`.

## GitHub Pages deployment

The public site is deployed from the `main` branch using [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). The workflow runs on each push to `main` and can also be started manually from the repository’s **Actions** tab. It installs dependencies with `npm ci`, builds using Node 20, and publishes `dist/` to GitHub Pages.

The workflow sets Vite’s base path to `/excel-tutor/`, which matches the project-site URL. For a local build that uses the same path, run:

```bash
npm run build -- --base=/excel-tutor/
```

GitHub Pages must use **GitHub Actions** as its publishing source. The repository is public, and the published site is publicly accessible over HTTPS.

## Data, persistence, and privacy

- Workbook cells, worksheet names, and reflection text are saved in the browser’s `localStorage` on that device and browser.
- The checklist state and tutor conversation are currently held in application memory; they may reset when the page is refreshed.
- There is no cloud save, user account, or cross-device synchronization.
- The tutor’s responses are generated by local, rule-based code. The app does not send questions to an AI service and does not require an API key.
- The sample dataset is included in the app. No backend is used to import or store it.

Because the GitHub repository is public, its source code is publicly viewable. Do not add secrets, API keys, or private data to the repository.

## Current prototype limitations

- Formula evaluation supports a limited set of operations: basic arithmetic between cell references, `SUM`, `AVERAGE`, `MAX`, `MIN`, `COUNT`, `MONTH`, `DAY`, and `YEAR`.
- The checklist recognizes some statistical function names, including `MEDIAN` and `STDEV.S`, but those functions are not currently evaluated by the spreadsheet formula engine. The checklist can therefore mark a step complete even when a formula result is not calculated correctly.
- Formula behavior, references, ranges, formatting, and worksheet behavior are simplified and may differ from Microsoft Excel.
- The AI Tutor is a set of scripted responses and keyword-based guidance, not a connected generative AI assistant.
- Undo and redo controls are visible in the toolbar but are not implemented yet.
- The checklist uses lightweight activity signals. It should be treated as learning progress feedback rather than automatic grading.

## Development notes

- Keep React 18 and React Magma 7 unless the project’s maintainers decide to upgrade them.
- Preserve the scenario’s existing task data and completion behavior when changing presentation or layout.
- Use tutoring or teaching language in learner-facing copy.
- Prefer React Magma components and semantic foundation colors for shared controls and status messages.
- Keep the Pages base path and hash-based routing compatible with `/excel-tutor/`.
